## Overview

Ryu Replay is a Windows desktop application for capturing gameplay and desktop moments, saving instant replays, and editing clips before sharing them.

## Download and install

1. Open [the latest release](https://github.com/D3N00N/Ryu-Replay/releases/latest).
2. Download **Ryu-Setup.exe** under **Assets**.
3. Run the installer and follow the setup prompts.

**Platform:** Windows x64.
